# TFG - Towards Explainable AI

This repository contains the code, processed data, and notebooks used for the undergraduate thesis “Towards Explainable AI for Psychosis Detection Through Clinical Language Modeling”.

The goal of the project is to investigate whether population-specific Language Models (separately adapted to healthy controls and psychosis patients) can capture and discriminate linguistic patterns associated with psychosis from transcribed clinical interviews, using simple and interpretable probabilistic measures (perplexity) as the basis for classification.

## Contents
- `code/` — Notebooks and small scripts organized by stages: preprocessing, training, evaluation, deployment and classifiers.
- `data/` — JSON datasets and CSV outputs used by experiments.
- `transcripts/Discourse-UWO` - transcriptions downloaded from PsychosisBank


## Dataset
The project relies on the Discourse-UWO corpus, a collection of clinical interviews recorded with the Discourse Protocol, including both healthy control participants and individuals with psychosis, as well as baseline and follow-up sessions.

The raw transcripts themselves are not included in this repository. To reproduce the experiments, users must:

1. Request access to the dataset through [PsychosisBank](https://talkbank.org/psychosis/index.html).

2. Download and store the transcripts in the appropriate directory, following the dataset’s terms of use and ethical guidelines.


## Full-run
1. Create a Python 3.12 virtual environment and activate it.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1    # For windows
source .\.venv\bin\activate     # For linux
pip install --upgrade pip
pip install -r requirements.txt
```

2. (Optional) Install `flash-attn` if training with fast attention kernels:

```powershell
pip install flash-attn --no-build-isolation
```

3. Create a Hugging Face token (you should add it in some notebooks)

4. Execution order and `code/` overview

Below is an outline of the files included in `code/` and a short description of each:

- `code/01_preprocessing/`

  - `ordered_healthy_preoprocessing_discourse.ipynb`: Notebook to preprocess and order healthy-control transcriptions.
  - `ordered_patient_preoprocessing_discourse.ipynb`: Notebook to preprocess and order patient transcriptions.
  - `analysis.ipynb`: Initial data exploration notes; visualizations and sanity checks.

- `code/02_training/`
  - `patient-training-gemma.ipynb`: Training notebook for the patient model.
  - `healthy-control-training-gemma.ipynb`: Equivalent notebook for the healthy-control model.

- `code/03_fidelity_validation/`
  - `fidelity_validation.ipynb`: Evaluation and fidelity analysis between models, plus comparative metrics.

- `code/04_model_deployment/`
  - `ollama-chat-updated.html`: Web interface to interact with the models through chat or videocall.
  - `ollama_proxy.py`: Serves the web interface and forwards requests to Ollama.
  - `HealthyModel/Modefile` and `HealthyModel/model.gguf`: Configuration file and the model prepared for Ollama (healthy control) (you should download the corresponding GGUF).
  - `PsychoModel/Modefile` and `PsychoModel/model.gguf`: Configuration file and the model prepared for Ollama (patients with psychosis) (you should download the corresponding GGUF).

  - Deployment note: for each model you must create and push it to Ollama. Example commands:

    ```powershell
    #cd []   place in the corresponding folder
    ollama create <username>/<model-name>
    ollama push <username>/<model-name>
    ```

- `code/05_classifiers/`
  - `individual/`
    - `llm-classifier.ipynb`: Evaluation of classifiers based on LLM responses (individual experiments).
    - `perplexity-classifier.ipynb`: Notebook that builds classifiers using perplexity as a feature.
    - `tf-idf_classifier.ipynb`: TF-IDF experiment with classical models for comparison.
  - `perplexity/`
    - `01_perplexity_calculator.py`: Script to compute perplexities using trained models.
    - `02_gb_classifier_group_mean.ipynb`, `02_gb_classifier_group_median.ipynb`: Training Gradient Boosting classifiers with group aggregates (mean/median).
    - `02_mlp_classifier_group_mean.ipynb`, `02_mlp_classifier_group_median.ipynb`: Training MLP classifiers with group aggregates (mean/median).
    - `graphs_joined.ipynb`: Visualizations and comparison plots of classifier results.
    - `temp_data/`: Folder for intermediate/temporary data generated by the notebooks.

Each folder contains notebooks/scripts intended to be executed in the order above: first prepare and order the data in `01_preprocessing`, then train models in `02_training`, evaluate in `03_fidelity_validation` and run classification experiments and analysis in `05_classifiers`.

##  Ethical considerations

This work involves the use of clinical interview transcripts, which must be considered highly sensitive medical data. For this reason, any collection, storage, processing, or deployment of AI-based systems in this domain must be carried out with special care, guaranteeing privacy, confidentiality, and strict compliance with data protection regulations. In addition, because these models operate in a mental health context, their outputs should always be interpreted with caution and under professional supervision, since an incorrect use or overinterpretation of the results could have serious consequences for patients.
